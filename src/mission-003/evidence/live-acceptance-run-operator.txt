Result: exactly 7 successful calls (200), matching the required 4

different credential) correctly failed closed with "HTTP 401: invalid

Browser-side network requests (captured via the browser's own network

Wall-clock: the run completed between two polling checks at +15s (4 of 7
calls already done) and +30s (all 7 done) after the click — so roughly
20-30 seconds end to end, consistent with the team's 20-60s estimate for
seven sequential claude-haiku-4-5-20251001 calls dominated by provider
latency. (This is bounded by operator polling granularity, not precise
instrumentation.)
