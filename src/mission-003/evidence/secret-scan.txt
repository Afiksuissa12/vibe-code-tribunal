5. THE .gitignore GAP  (see QA-2 — OPERATOR ACTION REQUIRED)
----------------------------------------------------------------------
    The root .gitignore covers *.local, so .env.local is ignored.
    It does NOT cover a plain .env. Verified by reading the file.
    It is outside this team's write policy and could not be fixed here.

    Mitigation established by experiment, not by argument: in a throwaway
    copy of this app outside the repository, a .env containing both
    ANTHROPIC_API_KEY=<synthetic> and VITE_ANTHROPIC_API_KEY=<synthetic>
    was created and `vite build` run. Neither value reached dist/ —
    a production build only inlines the VITE_ variables the code actually
    reads, and no code reads either. The sandbox was then deleted.
    So the exposure is committing the file, not shipping it. The proxy
    also loads no dotenv file, so a .env never has to exist at all.
